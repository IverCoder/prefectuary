# Prefectuary

Ang Prefectuary ay usa ka web app para mutan-aw ug magdugang sa rekord sa Prefect of Discipline.

Under development pa ni nga app. Palihug tuman sa [Conventional Commits](https://www.conventionalcommits.org/) ug [REUSE](https://reuse.software/)-compliance.

Mga planadong feature:
1. Offline web app paagi sa service workers
2. Pagtuman sa Material Design 3 guidelines
3. I-publish sa Flathub para sa Linux
4. I-publish sa F-Droid para sa Android

## Pag-abri

```
npm run dev -- --open
```
